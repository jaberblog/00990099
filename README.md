# VLESS VPN (Flutter + flutter_vless)

1. محتویات این پوشه را در یک ریپوی GitHub آپلود کنید (شاخه main).
2. به تب Actions بروید؛ workflow با نام "Build APK" خودکار اجرا می‌شود
   (یا Run workflow را بزنید).
3. بعد از اتمام، از بخش Artifacts فایل‌های APK را دانلود کنید
   (برای اکثر گوشی‌ها: app-arm64-v8a-release.apk).

افزودن کانفیگ جدید: لینک vless:// را به لیست kConfigs در lib/main.dart اضافه کنید.
